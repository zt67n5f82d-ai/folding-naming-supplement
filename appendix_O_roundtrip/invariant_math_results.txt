==========================================================================
不变量映射的量化验证  (样本 M = 40000, 任务数 = 4)
==========================================================================
不变量 I = 「进行中的任务必须有负责人」
合规状态占比 P(I) = 0.8491

接口                     往返缺陷         能否守住 I       H(视图)/bit    压缩率
--------------------------------------------------------------------------
π₁ 周报v1(只报计数)          0.8504       否            3.5274       0.2819
π₂ 周报v2(带负责人)          0.0000       是            8.9447       0.7149
--------------------------------------------------------------------------
H(具体域 X)          = 12.5115 bit
数据处理不等式检验    H(π(X)) ≤ H(X) : 3.5274 ≤ 12.5115  ✓
                      H(π(X)) ≤ H(X) : 8.9447 ≤ 12.5115  ✓

★ 「守住不变量」的信息代价 = H(π₂) − H(π₁) = 5.4173 bit
★ 缺陷从 0.8504 降到 0.0000 （这就是「从 A 值改善到 B 值」）

—— 硬下界（定理，不是估计）——
不变量自身的熵 H(I(X)) = 0.6122 bit
任何能判定 I 的视图都必须满足  H(π) ≥ H(I(X)) = 0.6122 bit
  （因为 I(X) 是 π(X) 的函数，由 DPI：H(I(X)) ≤ H(π(X))）
本设计的实际开销 H(π₂) = 8.9447 bit ≥ 下界 0.6122 bit  ✓

结论：
  · 缺陷 defect 是一个**可计算的标量**，接口改进 = 缺陷单调下降（可测、可回归）。
  · 但 π₁→π₂ 不是免费的：要守住不变量，必须**多付 5.42 bit**。
  · 两者都满足 H(π(X)) ≤ H(X)：折叠**不可能**凭空造信息（DPI）。
