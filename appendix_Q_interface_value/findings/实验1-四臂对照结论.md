# 实验 1（四臂对照）：接口三件套的边际价值 —— 结论

> 数据文件：`oc_all_results.jsonl`（184 条，172 条有效：含 `arm`+`hidden_all`+`ok`）
> 设计说明见同目录 `README-实验说明.md`。
> 任务：12 题（8 易 + 4 难），4 个免费模型（fledge-alpha / ling-3.1-flash / nemotron-3.5-lightning / nemotron-3-ultra），4 臂。
> 判定：抽取代码 → `exec` → 隐藏 oracle 断言，**无 LLM 裁判**。

---

## 0. 一句话结论

**本书的核心主张被强证据支持：把"契约（π 上行压缩视图 + α 下行有限原语）"写全，比"裸提示词"或"散文式完整规格"都显著更可靠；且分层形式（B）与散文（C）在性能上无差别——价值在信息，不在排版。**

这是承重结论。实验 2（修复回路）的阴性结果不触及它（见 `实验2-补样本结论-R45.md`）。

---

## 1. 四臂定义（同一道题，信息量逐步加码）

| 臂 | 给什么 | 隔离目标 |
|----|--------|----------|
| **A** 裸 | 目标 + 签名 | 基线 |
| **D** π/α | 目标 + 签名 + 完整返回值契约 + 约束，无示例 | π/α 信息量 |
| **C** 散文 | 与 D 同信息 + 可见示例，摊成一段散文 | 示例价值 |
| **B** 分层三件套 | 与 C **完全相同信息**，但切成 π/α/I 三段 + "违反即回退重写" | **分层形式本身的价值** |

关键对照 **C→B**：信息完全一致，仅"是否分层 / 有无回滚口令"不同。

---

## 2. 结果

### 2.1 全对率（hidden_all：所有隐藏断言一次过）

| 臂 | 全对率 | 逐模型（全对率） |
|----|--------|------------------|
| **A** 裸 | **27.9%**（12/43） | fledge 33% / ling 42% / nemotron-3u 25% / nemotron-3.5 9% |
| **B** 分层 | **95.5%**（42/44） | 四模型均 83–100% |
| **C** 散文 | **97.6%**（41/42） | 四模型均 ≥ 91% |
| **D** π/α | **97.7%**（42/43） | 四模型均 92–100% |

### 2.2 断言级通过率（hidden_pass / hidden_total）

| 臂 | 断言通过率 |
|----|-----------|
| A | 56.5%（148/262） |
| B | 95.9%（256/267） |
| C | 98.1%（252/257） |
| D | 99.2%（260/262） |

### 2.3 按难度拆（全对率）

| 臂 | 易档 | 难档 |
|----|------|------|
| A | 32%（10/31） | **17%**（2/12） |
| B | 97%（31/32） | **92%**（11/12） |
| C | 97%（31/32） | 100%（10/10） |
| D | 97%（31/32） | 100%（11/11） |

**最难的四题（h_varint / h_evaluate / h_schedule / h_compose）上，裸提示只有 17% 全对，分层后 92–100%。脚手架对最难的任务帮助最大。**

### 2.4 A→B 提升（全对率，逐模型）

| 模型 | A | B | 提升 |
|------|---|---|------|
| fledge-alpha | 33% | 100% | **+67pp** |
| ling-3.1-flash | 42% | 100% | **+58pp** |
| nemotron-3-ultra | 25% | 100% | **+75pp** |
| nemotron-3.5-lightning | 9% | 83% | **+74pp** |

**四个模型一致 +58~+75pp，方向零例外。** 这是"均匀性"：脚手架的增益不依赖具体模型，只依赖"有没有把契约写全"。

---

## 3. 怎样读（诚实版）

1. **承重结论（成立）**：A ≪ B≈C≈D。把契约写全（π+α）是可靠性的主因；散文（C）、分层标签（B）、示例（C 有 B 无但 C≈B）都不比"写全契约"更优。
2. **C→B ≈ 0**：信息相同，仅形式不同，性能无差。说明**分层形式本身不创造可靠性，它只是把"已经写全的契约"更省 token 地表达出来**。本书主张"分层"的真正卖点在此（低成本表达完整契约），而非"分层比散文更准"。
3. **D≈C≈B**：连"示例"和"回滚口令"都不带来性能增益——与实验 2 的阴性结论（回滚口令在回路里也无增益）**同向互证**。
4. **脚手架能抬升弱模型的 floor，但不能突破其 ceiling**：fledge 在 A 下 33%、B 下 100%（被抬到天花板）；但个别极难子题即便给 B 仍有模型做不出——脚手架不替模型"变聪明"。

---

## 4. 与用户公式的对应

> 分层的收益 = 压掉的不确定性 − 接口的代价 ＋ 命名的涌现特性（两笔，不并列相加，见 `第45轮B-判据的两笔结构与阴性结果的边界.md`）

- **压掉的不确定性（大）** = A→B/C/D 的 +60~75pp 全对率提升，尤其难档 17%→92%。
- **接口的代价（小）** = 写 π+α 契约的 token 成本；但 D（π/α 简洁）性能≈C（散文冗长），说明这笔代价被"更省 token 达同等性能"抵消。
- **命名的涌现特性（小但真实）** = α 的边际贡献（见 `实验3-α单独消融结论.md`，约 +4pp）与"分层形式使组合可行"的副效用。

## 5. 外推限制（必须写明）

- 全部为**免费小模型**，结论**不能外推到 GPT/Claude 级模型**；在更强模型上，裸提示基线本身更高，脚手架的相对增益可能更小（绝对值仍可能为正）。
- 任务为算法/解析类单函数题，不含多文件、长上下文、工具调用等真实 Agent 场景；真实项目证据见 `swe_agent_fde_evidence.md` 与第 29/30 轮文档。

## 6. 对书稿的影响

- 正文/附录关于"契约优于散文、脚手架抬升可靠性"的表述**有实验支撑，可保留并引用本文件**。
