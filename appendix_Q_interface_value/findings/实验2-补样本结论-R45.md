## 4. 怎么读这个结果（诚实版）

1. **方向对、但不显著。** 2 个不一致对子全部偏向"不变量"，方向 2/2；但 p=0.500，且不一致对子仅 2 个——**统计上完全无法拒绝"两者无差异"**。
2. **零假设不能被推翻，就老老实实说没测出。** 本书从不宣称"回滚口令在回路里有效"，所以这与正文/附录**不矛盾**，反而是一份"我们测了、没测出，所以不这么说"的留档——与全书"把边界写进书里"的人格一致。
3. **它和附录的其它结论是一致的，不是矛盾的。**
   - 实验 1 已测出 **C≈B≈D**：价值在"把契约写全"（A→D，+60~75pp），不在"分层形式 / 回滚口令"（C→B≈0）。
   - 本实验从**回路**角度给出同向阴性证据：**不变量的价值不在"改错时怎么说"，而在别处**——它决定压掉的语义有没有泄漏，是**检查口 / 校验点**，不是咒语。
4. **外推限制**：全部免费小模型，不能外推到 GPT/Claude 级。在更强的模型上，"改错说法"的边际影响可能更小（基线本来就高）。
