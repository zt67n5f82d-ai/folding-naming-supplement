# 真实 LLM 实验：接口三件套的边际价值

**运行环境**：本地 OpenCode 后台服务（`opencode-cli.exe` v2.0.23，`http://127.0.0.1:49374`），
使用其内置的**免费模型**（provider `opencode`）。全部推理在本机发起、由免费端点执行，成本为 0。

**判定方式**：机械判定。抽取模型返回的代码 → `exec` → 跑**隐藏断言集**。
全程没有任何 LLM 充当裁判。判定器本身先用手写"金标实现"自测通过（见 `oc_oracle_selftest.py`）。

---

## 1. 为什么要这样设计

书里主张的"接口三件套"是 **π（上行压缩视图）/ α（下行有限原语）/ 不变量（违反即回滚）**。
天真地做实验（"给了三件套 vs 什么都不给"）会得到一个**无法解释**的结果，因为两组之间
差了三种东西：信息量、排版形式、以及回滚指令。必须把它们拆开。

因此设四个臂，**同一道题**：

| 臂 | 给什么 | 用来隔离 |
|----|--------|----------|
| **A** 裸模式 | 只给目标 + 函数签名 | 基线（"凭感觉写"） |
| **D** 分层 π/α | 目标 + 签名 + 完整返回值契约 + 约束，**无示例** | π/α 的信息量 |
| **C** 完整规格·平铺散文 | 与 D 同信息，**再加可见示例**，但全部摊成一段散文，无 π/α/I 标签、无回滚指令 | 示例的价值 |
| **B** 分层接口三件套 | 与 C **完全相同的信息**，但显式切成 π/α/I 三段，并加上"违反即视为未完成、必须回退重写" | **分层形式本身的价值** |

关键对照是 **C → B**：信息量完全一致，只有"是否分层、是否有回滚口令"不同。
如果 B 显著优于 C，说明分层形式本身有价值；如果 B ≈ C，说明价值全在信息里，**不在排版上**。

> **α 单独消融（实验 3）**：在 `oc_tasks.py` 新增 **D0 臂**（只给 π 上行契约，**不给 α 下行原语**），
> 与 D 臂对照，隔离 α 的净价值。结论见 `实验3-α单独消融结论.md`——α 仅约 +4pp 边际红利，π 才是主项。

## 2. 两个判据集：可见契约 vs 隐藏 oracle

每个任务有两组断言：

- **visible（可见）**：写在提示词里，用来**定义契约**。
- **hidden（隐藏）**：从不展示给模型，用来**打分**。

这样既公平（C/B/D 看到同一份契约），又防止模型对着可见断言硬编码（过拟合）。
隐藏断言全部可由契约推出——审计中发现 `chunk` 的 `n<=0 → ValueError` 从未在契约里说明，
属**不公平的隐藏测试**，已把该条款补进契约（见 `oc_tasks.py`）。

## 3. 任务集

**易档（8 题）**：`chunk` / `parse_duration` / `merge_intervals` / `to_roman` /
`rle` / `top_k_frequent` / `crc8` / `fixed_point`
——单函数、契约短，但对契约细节敏感（相接区间是否合并、次数是否恒写出、CRC 参数等）。

**难档（4 题）**：`h_varint`（LEB128 编解码）/ `h_evaluate`（递归下降表达式求值）/
`h_schedule`（加权区间调度 + 字典序并列规则）/ `h_compose`（在既有 `rle_encode`/`rle_decode`
之上做组合）
——多子句、相互牵制，用来**打破天花板效应**：易档里 C 和 B 都顶到 100%，无法比较。

## 4. 文件

| 文件 | 作用 |
|------|------|
| `oc_client.py` | 本地 server 客户端（HTTP Basic，用户名 `opencode`，口令取 `~/.config/opencode/service.json`） |

| `实验1-四臂对照结论.md` | 实验 1 结论：A≪B≈C≈D，承重结论（脚手架抬升可靠性） |

## 5. 复现

> 本节是当时原样存档，只把两处本机绝对路径（Python 解释器路径、实验目录）换成了通用写法。
> 完整说明与三种复现层级见仓库根目录 `README.md` 与上一级 `README.md`。

```bash
cd code                            # 本目录：脚本与任务定义都在这里
unset http_proxy https_proxy HTTP_PROXY HTTPS_PROXY ALL_PROXY all_proxy

python oc_oracle_selftest.py       # 必须 ALL PASS，否则判定器不可信（不需要模型）
python rescore.py                  # 从原始记录重算表 74–77，与书里逐格比对（不需要模型）
python oc_ab.py --models opencode/nemotron-3.5-lightning-free,opencode/ling-3.1-flash-free \
                --arms A,B,C,D --workers 5   # 重跑生成：需要本机模型服务，见 oc_client.py
```

> 注意：`http_proxy` 等环境变量会劫持 `127.0.0.1` 请求，必须 `unset`（`oc_client.py` 里也对
> localhost 请求单独绕开了代理）。
